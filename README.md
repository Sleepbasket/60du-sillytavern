# 60度 · SillyTavern 主题扩展（0.4.1 测试版）

本测试版将提供的完整 CSS 和四份酒馆助手脚本迁入独立扩展：Topbar、茶包首页、接待台、茶间留笺。还包含右上角四条规整的深茶色矩形快捷条、主题设置、昼夜模式、角色横幅调节、正文字号、仅作用于聊天正文的夜间背景。关闭扩展时会移除自身样式、按钮、监听器和新增节点。

## 最简单的本地测试

1. **先关闭酒馆助手里的这四份旧脚本和旧全局主题 CSS**，避免它们与扩展同时修改界面。SillyTavern 原生美化面板的 CSS 会由本扩展暂时停用，无需删除。
2. 解压 ZIP，得到 `manbei-shoutie` 文件夹。确认 `manifest.json` 就在该文件夹里面，不要多套一层目录。
3. 在本地 SillyTavern 安装文件夹中打开 `data/default-user/extensions/`，把整个 `manbei-shoutie` 文件夹复制进去。最终应看到 `SillyTavern/data/default-user/extensions/manbei-shoutie/manifest.json`。如果使用了其他用户，将 `default-user` 换成对应的用户目录。[SillyTavern 扩展目录说明](https://docs.sillytavern.app/for-contributors/writing-extensions/#manifestjson)
4. 重启或重载酒馆，在「扩展 → 管理扩展」中查看「60度」。先打开一个普通角色聊天，检查右上角四条、留笺正文，再到新建聊天首页检查茶包和接待台。

测试期间修改源文件后，只需替换对应文件并重载页面。要回退，在扩展管理器里禁用本扩展并重载；若旧版酒馆不执行禁用钩子，直接移走 `manbei-shoutie` 文件夹再重载。

若已安装旧测试版：退出或关闭酒馆页面，先备份原 `manbei-shoutie` 文件夹，再用新版同名文件夹整体替换，重新打开酒馆。扩展设置保存在酒馆用户数据中，替换文件夹不会清空已有的横幅、字号等设置。

## 正式用 Git URL 安装

测试稳定后，将**本文件夹内的文件直接放在 Git 仓库根目录**，其中根目录必须有 `manifest.json`。在酒馆「扩展 → 安装扩展」中输入该仓库 URL，即可安装，后续也方便更新。SillyTavern 官方安装入口接收的是 Git 仓库 URL，不是本 ZIP 文件的路径。[官方扩展安装说明](https://docs.sillytavern.app/extensions/#third-party-extensions)、[扩展清单规范](https://docs.sillytavern.app/for-contributors/writing-extensions/)

## 迁移内容

- `topbar.js`：迁入「美化」脚本。角色与聊天切换改用 SillyTavern context 和原生事件，不依赖酒馆助手的全局函数。
- `tea-home.js`：迁入「新建聊天」脚本。保留茶包卡、角色分组、聊天展开，以及调用原生置顶、重命名、删除按钮的行为。
- `reception.js`：迁入「接待台」脚本，保留原欢迎语和远程茶小二图片；扩展启用时按欢迎页状态挂载，禁用时撤销。
- `letter.js`：迁入「正文部分」脚本。保留信首、落款、题签和翻页控制，并修正原脚本曾缺失的 `scheduleSync()`。
- `theme.css`：保留原 CSS 在第 1–21 范围内实际存在的各部分（原文件本身没有编号 15、18），并新增设置面板和夜间样式。原先直接作用于根节点、`body` 和 `#bg1` 的规则已加上主题启用条件；禁用时整张样式表会移除。

右上角前三条默认打开预设、API、世界书原生抽屉；第四条打开扩展设置。角色焦点配置以头像文件名为键，避免重名冲突。夜间上传图存于当前浏览器的 `localforage`，不会随 ZIP 或 Git 仓库分享。恢复默认会清除这张图。

0.3.0 修正了四条快捷入口的位置：它们位于收起后的角色横幅右侧，展开顶部工具栏时隐藏。夜间角色背景现在覆盖顶部栏、聊天正文和输入区所处的连续中央画布；设置抽屉仍是纯色。设置面板的滑块、选择框、开关改为无边框底色设计，并调整了夜间开篇题签、引用、输入图标、弹出菜单、角色列表悬停、预设数字输入框与新建聊天茶包卡的对比度。酒馆助手脚本与文件夹卡片也随昼夜模式切换底色与文字色。

0.3.1 补齐夜间欢迎页配色：茶包卡和展开记录改用深茶灰底色；“其他口味”的名称、摘要、日期与操作菜单改成可读的浅色，并收敛悬停亮度；“茶小二”介绍、Tips 和下方按钮也使用夜间底色与文字色。

0.3.2 为夜间聊天背景新增左右、上下焦点滑块。角色图片的位置按角色保存，上传图片的位置单独全局保存；左上角色横幅的焦点设置不受影响。角色背景目前已经读取头像原图而非缩略图。若原图分辨率不足，铺满聊天画布时仍会被放大；可改用更高分辨率的上传图片来获得真正清晰的背景。右上四条矩形快捷条进一步收紧间距，四条的宽度和高度各不相同，夜间茶色也稍微提亮。

0.3.3 修正了夜间用户设定卡片的悬停亮底、选中态和姓名黑底；统一原生确认弹窗、旧式弹窗和酒馆助手编辑弹窗中“确定／取消／否”按钮的夜间底色与悬停色；设置面板中的选择框、按钮和上传入口改用与其他设置文字相近的字号及较紧凑的高度。

0.4.0 把显示名称改为「60度」，并让「用户设置 → UI 主题」直接切换本扩展与其他主题。名称取自热黑咖啡约 60°C 的常见饮用偏好；这是命名灵感，并非所有美式咖啡的唯一最佳温度。[黑咖啡温度研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9712614/)

0.4.1 针对 TauriTavern 的「聊天 DOM 虚拟化」接入 ChatSurface 消息挂载回调。历史消息被移出并重新放回页面时，信笺样式会重新应用；开篇题签随第 0 条消息挂载，不再作为额外的聊天列表节点。普通 SillyTavern 继续使用原有监听方式。[TauriTavern ChatSurface 契约](https://github.com/Darkatse/TauriTavern/blob/main/docs/API/ChatSurface.md)

## 在 UI 主题下拉框里切换

安装并启用扩展后，在「用户设置 → UI 主题」选择「60度」即可启用整套主题；选择其他主题会即时撤掉本扩展的样式、快捷条和页面装饰，并让 SillyTavern 应用所选主题。再次选择「60度」即可切回来，无需在扩展管理器里禁用。切换状态会保存，重载后保持上次选择。

选择「60度」时，原生自定义 CSS 会暂时停用，原生主题的保存、更新、删除、导入、导出和 CSS 编辑入口暂时锁住，避免把本扩展误存为原生主题。选择其他主题后这些入口恢复；原有主题文件和设置不会被删除。切换到其他主题不等同于卸载扩展；仍可在扩展管理器中完全禁用。

内部文件夹名与设置键继续使用 `manbei-shoutie`，以便覆盖旧测试版时保留横幅、字号等个人设置。其他扩展自行注入的 CSS 不受原生主题选择器控制，因此迁入的四份酒馆助手旧脚本仍需关闭。

## 已知限制与实机检查

- 原 CSS 第 19–20 部分大量依赖特定版本酒馆及 Tavern Helper 的 DOM 类名；夜间仍有少量固定浅色。请实机检查常用面板，发现异常可提供截图逐页调整。
- 茶包首页和接待台依赖酒馆原生欢迎页结构。接待台只在原生 Assistant 欢迎消息存在、且内容包含原脚本指定的中文提示时出现；这是原脚本的触发条件。
- 留笺脚本会移动原生翻页按钮并在 `#chat` 插入题签；请在本地 SillyTavern 中重点检查翻页与长聊天。
- 快捷条使用当前版本的原生按钮 ID。若宿主版本更改 ID，点击时会提示找不到入口。收起顶部栏时点击原生抽屉的组合行为也需实机检查。
- 原 CSS 使用远程字体，接待台图片也来自原脚本的远程地址；离线时字体回退，图片可能无法显示。
- 本交付已通过脚本语法、清单和 ZIP 完整性检查。0.4.1 的模拟浏览器测试覆盖了 25 条初始消息、重新挂载第 26–50 条、绝对楼层编号、清理和重新启用；这些消息都重新获得信笺装饰。此前在本地 SillyTavern 1.17.0 实测了「60度 → Dark Lite → 60度」及「60度 → 慢烘50度 → 60度」往返切换。**仍未在真实 TauriTavern 中验证**虚拟滚动与其他扩展同时运行的效果；背景焦点按角色切换后的持久化、扩展管理器禁用后的即时恢复、图片上传后重载和手机布局也待检查。

原生主题色建议维持：斜体 `#817769`、主要 `#38352F`、下划线 `#9C815D`、引用 `#826448`、阴影 `#38352F`、聊天与 UI 背景 `#F8F7F1`、UI 边框 `#C9B9A2`（73% 不透明度），其余两项透明度为 0。扩展不会改写用户保存在酒馆里的主题色设置。
